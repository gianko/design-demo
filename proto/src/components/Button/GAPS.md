# Button: gaps

Places the brief, ADRs or tokens didn't decide something Button needed, the call made, and the alternative.

1. **Button height has no token.** The brief sets a minimum target (24/44px) but no button height. Call: `min-h-target` + `py-3xs` + `text-label` line height, which renders 30px on admin and 44px on contractor. Alternative: a `--height-control` density token (e.g. 32/44px) shared with inputs and segmented filters, so controls in one row line up.
2. **Horizontal padding doesn't follow density.** No density token for control padding, so both densities use `px-sm` (16px). Alternative: a density padding token (12px admin, 16–20px contractor).
3. **No destructive or quiet (ghost) intent.** The brief names only primary actions and the secondary control edge, and status colours "never borrow the accent", which suggests they aren't action colours either. Call: two intents. Alternative: a `danger` intent on its own role pair (e.g. for "Void invoice"), and a quiet intent for toolbar actions. Both need new colour roles first.
4. **Pending label and announcement.** The brief defines the progress edge but not whether the label changes ("Paying…") or how screen readers hear progress. Call: the label stays as written, the button gets `aria-busy` + `aria-disabled` and stays focusable. The result is announced by whatever confirms it (the toast). Alternative: a polite live region inside Button, or a `pendingLabel` prop.
5. **Disabled semantics.** Unstated. Call: native `disabled` (out of the tab order); pending uses `aria-disabled` so focus doesn't drop mid-operation. Alternative: `aria-disabled` for disabled too, so a keyboard user can reach the button and hear why it's unavailable. That needs a description pattern the library doesn't have yet.
6. **Sweep restart.** The tokens give two keyframes: fill (scaleX 0→1) and sweep (translateX −100%→100%, starting at 320ms). Nested, the edge fills, then visibly jumps from full to empty as the sweep begins. Alternative: a sweep keyframe starting at `translateX(0)`, or a narrower sweep segment, which is a tokens change.
7. **Edge sits inside the border.** `overflow-hidden` clips to the padding box, so on `secondary` the 2px heather edge sits on top of the 1px `control` border. Accepted at this size. Alternative: drop the bottom border while pending, which needs a `border-b-transparent`-style call the brief doesn't make.
8. **Icons.** There's no Icon component or icon registry, and a ReactNode can't be expressed in the Zod registry. Call: an `icon` prop that's an enum over a small Phosphor map (`check`, `download`, `send`, `plus`), leading only. Alternative: an `icon` slot taking a future Icon node, with the name list owned by Icon's registry entry.
9. **Registry `slots`.** ADR 0004 names slots for child nodes; Button has none (text is a `label` prop, per "every user-facing string is a literal prop"). Call: `slots: []`. The `tv()` slots (`root`, `icon`, `label`, `edge`, `sweep`) are internal parts, not registry slots.
10. **No full-width option.** Contractor screens on a phone often want a full-width primary. Call: none, until a layout component (Stack) can stretch its children. Alternative: a `width: "fit" | "fill"` prop.
